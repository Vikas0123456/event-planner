# 🚀 Quick Setup Guide

## Step 1: Install Dependencies

```bash
npm install
```

## Step 2: Start Development Server

```bash
npm run dev
```

Your website will open at `http://localhost:3000`

## Step 3: Customize

### Update WhatsApp Number

Search and replace `917067059611` in these files:
- `src/components/Hero.jsx`
- `src/components/Contact.jsx`
- `src/components/Footer.jsx`
- `src/components/Navbar.jsx`
- `src/components/SpecialOffers.jsx`

### Replace Gallery Images

Edit `src/components/Gallery.jsx` and replace the Unsplash URLs with your actual images.

### Update Contact Information

Edit contact details in:
- `src/components/Contact.jsx`
- `src/components/Footer.jsx`

## Step 4: Build for Production

```bash
npm run build
```

The production files will be in the `dist` folder.
